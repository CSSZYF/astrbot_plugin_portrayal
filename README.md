# astrbot_plugin_portrayal_csszyf

人物画像插件的 CSSZYF 维护版，已独立为单独插件 ID，不再与原版更新记录冲突。

</div>

## 兼容性

- AstrBot `3.4+`
- OneBot 11 / AIOCQHTTP
- `NapCat`
- `LLOneBot`

## 安装

建议按独立插件目录安装：

```bash
cd /AstrBot/data/plugins
git clone https://github.com/CSSZYF/astrbot_plugin_portrayal astrbot_plugin_portrayal_csszyf
```

安装后，AstrBot 中显示的插件名为 `astrbot_plugin_portrayal_csszyf`。

## 配置

在 AstrBot 面板中进入：

`插件管理 -> astrbot_plugin_portrayal_csszyf -> 操作 -> 插件配置`

## 说明

- 本仓库为独立维护版本
- 插件内部数据目录也使用独立 ID
- 不再与原版 `astrbot_plugin_portrayal` 共用同一插件标识
